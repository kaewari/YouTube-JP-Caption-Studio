# BỘ KIỂM THỬ THỦ CÔNG: ỨNG DỤNG WEB QUẢN LÝ TỪ VỰNG ĐÃ LƯU (SAVED ITEMS WEB APP)
**Mã tài liệu:** `TC_WEB_SAVED_ITEMS`  
**Module tương ứng:** MOD-13 (Saved Items Web Application & Extension Popup Export)  
**Tác giả:** Senior QA Architect & SDET  
**Tiêu chuẩn:** STLC Framework v1.0  

---

## 1. TỔNG QUAN PHẠM VI KIỂM THỬ
Tài liệu này định nghĩa chi tiết các ca kiểm thử cho ứng dụng Web App và Popup tiện ích quản lý từ vựng và câu đã lưu (`web/saved-items` phát triển bằng Next.js): giao diện hiển thị dạng lưới (Grid View), bộ lọc đa tiêu chí (cấp độ JLPT N5 đến N1, nhãn Tag, nguồn video), công cụ tìm kiếm tức thì, chức năng sao chép và xuất dữ liệu sang Anki/CSV, khả năng xử lý khi Local Bridge ngoại tuyến, và quy trình build tĩnh phục vụ nhúng vào Extension Popup.

## 3. TIÊU CHÍ ĐÁNH GIÁ NGHIỆM THU (PASS/FAIL CRITERIA)
- **PASS:** Giao diện dạng lưới hiển thị đầy đủ thông tin, lọc JLPT và tìm kiếm tức thì chuẩn xác, xuất Anki CSV chuẩn UTF-8, build static export Next.js đạt exit code 0 không lỗi typecheck.
- **FAIL:** Build Next.js bị lỗi TypeScript/ESLint, tìm kiếm bị treo khi gõ nhanh, hoặc dữ liệu lưu không đồng bộ hiển thị trên Web App.
