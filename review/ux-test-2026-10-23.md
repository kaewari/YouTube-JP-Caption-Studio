## 2. iOS Simulator — tìm ra 1 crash thật, đã sửa

**Crash lúc launch (Debug):** cả 2 app crash ngay khi mở trên simulator.
`DiagnosticReports` cho thấy `EXC_BREAKPOINT` tại `BackupSmoke.run()`
(`BackupService.swift:586`, gọi từ `App.init`) — assert `"duplicate videoId must fail
the apply"`. Nguyên nhân gốc: SwiftData **không throw** khi trùng unique attribute
(đã chứng minh bằng binary riêng trên store file-backed macOS: `SAVE_DID_NOT_THROW`,
row count 1 — lặng lẽ dedup). Assert này chỉ chạy ở `#if DEBUG` nên Release không sao,
nhưng mọi bản Debug mở là chết — và CI không bắt được vì CI chỉ build, không launch app.

**Sửa:** `apply()` tự kiểm tra trùng `videoId` trước khi đụng store
(`SnapshotError.duplicateVideoId`, không thêm public API) — hành vi đảm bảo trên mọi
stack thay vì nhờ store throw. Đồng thời bỏ carve-out `#if !os(macOS)` trong harness
(vì assert giờ đúng ở mọi nơi — suite mạnh hơn trước).

**Verify sau sửa:** iPad 3/3 launch xanh + terminate sạch, 0 crash mới; iPhone 3/3 launch
xanh + video 30s (`iphone_launch.mp4` trong `.tmp-ux-*/`, đã kiểm tra frame); app foreground,
video play, phụ đề JP chạy (`りこてや?` → `うん、まぁ…` → `ほらあそこに座ってる`).
Ảnh: `ux-test-evidence-2026-10-23/`.

## 3. Extension — tìm ra bug thật: MAIN world chưa từng được inject

Chuỗi chẩn đoán (mỗi bước có log thật, không đoán):

1. Overlay không hiện sau 90s. `chrome://extensions` trống + log verbose:
   **`--load-extension is not allowed in Google Chrome, ignoring`** — Chrome brand
   chặn load unpacked qua CLI (chỉ Chromium/Dev mới cho). Các "SW lạ" trước đó đều
   là component của Chrome (xác minh bằng `chrome.permissions.getAll()`).
2. Chuyển sang Playwright Chromium (`ignoreDefaultArgs: ['--disable-extensions']`
   vì Playwright cũng tự thêm `--disable-extensions`): extension cài được, content
   script inject được (`#hardsub-ocr-root` có).
3. Overlay vẫn trống → console lặp lại:
   `Unsafe attempt to load URL chrome-extension://.../timedtext_parse.js?api=7 ...
   Domains, protocols and ports must match`.
   Thử `fetch()` đúng 2 URL đó → **HTTP 200** ⇒ file hợp lệ, chỉ thẻ `<script>` bị chặn.
4. Kiểm tra header: YouTube gửi `content-security-policy: require-trusted-types-for
   'script'` + `script-src` không cho scheme `chrome-extension:`. Vậy thẻ script
   trỏ vào extension luôn bị CSP chặn → `window.__HARDSubOCRCapture` không tồn tại
   → bridge MAIN-world không trả lời PING → mọi đường fetch caption rơi hết → overlay
   không bao giờ hiện. **Đây là bug thật, ảnh hưởng mọi user Chrome.**

**Fix (`e465a2d`):** inject bằng `chrome.scripting.executeScript({world:"MAIN",
files:[...]})` — đọc file từ đĩa, **miễn nhiễm CSP của trang**. Version + capability
token chuyển sang marker element (`data-cap`/`data-api`), `page_capture.js` vẫn đọc
`?cap=` làm fallback. Guard-reset khi force-reinject cũng là inline `<script>` (cùng
bị chặn) → đổi sang `executeScript({func})`. Thêm permission `scripting`
(min_chrome_version đã là 116; `world:"MAIN"` cần 111+).

**Verify (Chromium thật, YouTube live, sau fix):**
```
captureApiVer: 7 · hasHandler: true · parser: object · markerCap: 36 ký tự
CSP/Unsafe errors: 0   (trước fix: 2 lỗi mỗi lần inject + bridge không tồn tại)
```
Suite extension 15/15 · sanity 22 passed/5 skipped · anti-fake gate PASSED.

**Trạng thái profile của user (kiểm tra qua bsk, 22:35):** extension hiện **không chạy**
trong Chrome của bạn — tab YouTube không có `#hardsub-ocr-root`, console không có dòng nào từ
extension id `oiocgalcdfmkbcikemohekbjjmlbpoll`, network 0 request tới nó. Manifest đã
validate hợp lệ (permissions + mọi file tồn tại) nên không phải lỗi load. ⇒ cần bật/reload
extension trong `chrome://extensions` (bsk bị sandbox chặn `chrome://` nên tôi không tự làm được).

**Còn lại ở phía user:** extension trong Chrome của bạn đang chạy bản cũ → phải
**Reload** ở `chrome://extensions` (hoặc Remove rồi Load unpacked lại từ thư mục
repo hiện tại) mới có fix. Chưa verify được caption thật trong phiên Chrome ẩn danh
của Playwright (YouTube trả 401/403 cho timedtext khi không có session), nên bước
xác nhận cuối là trên browser đã đăng nhập của bạn.
